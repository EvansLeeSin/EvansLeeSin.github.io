2026 年 11 月 2 日，美团正式上线 LongCat-2.5。此前，该模型已于 9 月 25 日推出预览版。LongCat-2.5 是一款原生多模态的混合专家（MoE）模型，面向长周期 Agent 任务，覆盖终端、浏览器、图形界面、电子表格和设计工具等场景。

<!-- more -->

## 模型规模与定位

LongCat-2.5 的总参数为 1.6 万亿，每 token 激活约 480 亿参数。美团将其定位为面向长周期 Agent 工作的模型，适用于需要多步骤持续执行的工作，例如终端操作、仓库级代码修改和自动化工作流。相较于 LongCat-2.0，2.5 版本的主要变化是增加了原生的视觉理解能力。

据报道，LongCat-2.5 在国产 AI 加速器上完成训练。美团方面表示，模型把真实 Agent 任务中遇到的失败案例转化为可复现的训练任务，用于改进长周期任务的执行表现。

## 上下文与输出

LongCat-2.5 的上下文窗口为 100 万 token，最大输出长度为 12.8 万 token。这一组合面向需要一次性读入大量代码库、长文档或多阶段工作流的 Agent 场景。

模型通过美团的在线对话服务和 API 平台提供，API 同时支持 OpenAI 与 Anthropic 两种请求格式。模型也已上线 Vercel AI Gateway，模型标识为 `meituan/longcat-2.5`，上下文与输出规格与美团平台一致。

## 定价

美团平台公布的按量付费价格为限时折扣价：每百万 token，未缓存输入 0.30 美元，缓存输入 0.006 美元，输出 1.20 美元。平台同时注明价格可能调整，以平台账单为准，未公布折扣的结束日期。

## 官方评测

根据官方公布的评测结果，LongCat-2.5 在 Terminal Bench v2.1 上得分为 88.4，在 Terminal Bench v4.0 上为 38.5，在 DeepSWE v1.1 上为 64.6，在 BrowseComp 上为 91.9。官方表示，上述分数均在开启思考、temperature 为 1.0、top_p 为 0.95 的条件下取得。

## 权重发布情况

目前 LongCat-2.5 仅通过对话服务和 API 提供。据报道，模型权重在 GitHub 与 Hugging Face 上标注为即将推出，尚未正式发布。

## 背景

LongCat-2.0 于 2026 年 6 月发布，LongCat-2.5 是该系列的后续版本。美团以本地生活服务业务为人所知，LongCat 是其面向 Agent 与编程场景的模型系列。
