2026 年 11 月 4 日，腾讯混元团队发布 Hy4 正式版。相比 8 月 28 日发布的预览版，正式版新增视觉理解与电脑操作两项能力，并已通过腾讯云与 OpenRouter 提供 API 接入。腾讯在发布文章中称，Hy4 首次跻身最强开源模型之列，同时也承认与顶级闭源模型之间仍存在较大差距。

<!-- more -->

## 视觉与电脑操作

Hy4 首次具备视觉理解能力，可以处理细粒度的图像细节并分析复杂图表。电脑操作方面，模型可以跨命令行与图形界面操作计算机，并针对 Blender、CAD 等专业软件以及跨多个应用的长流程任务做了专门训练。腾讯表示，正式版在预训练与后训练规模上都比预览版有大幅提升，在指令遵循、长上下文理解、长时任务与深度研究方面均有进步。

在应用侧，Hy4 已接入元宝、ima、WorkBuddy、CodeBuddy 以及企业微信智能助手 Dayuan。腾讯还提到，模型可以与用户实时协作编辑 Word、Excel 与 PowerPoint 文件。

## 定价与接入

API 定价与预览版保持一致：输入每百万 token 0.834 美元，输出每百万 token 2.501 美元，缓存输入每百万 token 0.042 美元。OpenRouter 的页面显示约 100 万 token 的上下文窗口与 65,536 token 的输出上限，接受文本与图像输入，输出为文本，目前唯一服务商为腾讯云。OpenRouter 页面另显示 50% 的折扣价。

## 评测表现

腾讯在发布文章附录中公布了一张 34 项评测的对照表，对比对象包括 Hy4 预览版、GLM-5.3、DeepSeek-V4.1-Flash、Kimi K3.1 Pro 以及 GPT-6.1 Sol 与 Claude Opus 5.5 两款闭源模型。其中 20 项为腾讯内部评测，多数竞品分数来自腾讯自己的测试。

在 OSWorld 2.1 电脑操作评测中，Hy4 得分为 78.9，Claude Opus 5.5 为 81.8，Kimi K3.1 Pro 为 79.6；在 Terminal-Bench 4.0 终端任务评测中，Hy4 为 44.4，Claude Opus 5.5 为 66.4。腾讯同时表示，在金融场景的内部评估中，213 位专业人士在 579 项真实任务上对模型打分，Hy4 在开源模型中排名第一，得分 3.04（满分 4 分）。在内部搜索评估中，幻觉率从预览版的 15.76% 降至 5.45%。

## 权重与后续计划

与 8 月预览版首日即开源权重不同，正式版的模型权重尚未发布。腾讯表示计划开源模型权重并随附更完整的系统卡，但未给出具体时间，目前其 Hugging Face 账号上只有 Hy4-preview 及其 FP8 版本。腾讯还计划在近期推出 Hy4 Flash，定位是成本更低、推理更快的轻量版本。腾讯同时承认，在研究级数学、长时编程、模型自我改进与高级视觉问答等自研高难度评测上，与顶级闭源模型的差距仍然较大。
