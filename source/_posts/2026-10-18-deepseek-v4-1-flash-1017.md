2026 年 10 月 17 日，DeepSeek 发布了 DeepSeek-V4.1-Flash-1017，这是 9 月发布的 V4.1-Flash 的一次检查点更新（checkpoint update）。新模型已上线 DeepSeek 的网站、App 与 API，通过已有的 `deepseek-flash` 模型名调用，调用方式不变；权重以 MIT 协议开源，已发布到 Hugging Face 与 ModelScope。DeepSeek 把这次更新称为"性能与成本上的帕累托改进"：评测分数上涨，同时任务完成更快、输出更短。

<!-- more -->

## 评测表现

据 DeepSeek 自身公布的对比表，1017 在全部 11 项报告的评测上都超过了 9 月版 V4.1-Flash，涨幅从 2.0 到 11.1 个百分点。其中 Agent 编码类评测涨幅最大：Terminal-Bench 4.0 从 31.2 升至 42.3（涨 11.1），ProgramBench 从 20.3 升至 29.1（涨 8.8）。DeepSWE v1.1 达到 77.0（前版 74.2），在 DeepSeek 的对照表中领先 Claude Opus 5（74.0）与 GPT-5.6 Sol（73.0）；其余上涨的项目包括 Apex Bench v1.1（64.6→72.1）、Automation-Bench v1.0.6（54.8→60.5）、Agents' Last Exam（31.8→35.4）、NL2Repo-Bench（65.4→68.2）与 ZeroBench-main（49.0→51.0）。

同一份对照表也显示了对手占优的项目：Humanity's Last Exam（无工具）上 Claude Opus 5 为 56.3，1017 为 42.6；Terminal-Bench 4.0 上 Opus 5 为 51.8。这些均为 DeepSeek 自报分数，尚未有独立复现。

## 定价

API 价格维持不变：输入每百万 token 0.15 美元，输出每百万 token 0.60 美元。上下文窗口为 100 万 token，最大输出在 256K 以上。DeepSeek 表示新版本在相同价格下输出更短、任务完成更快，因此单个任务的实际成本更低。

## 首次开放官方搜索与抓取 API

与模型同日发布的是 DeepSeek 自研搜索引擎的 Search 与 Fetch API，首次向所有开发者开放。DeepSeek 称该搜索引擎每天处理数亿次请求，API 按每千次调用 0.75 美元计费。经 DeepSeek Harness、Claude Code 或 Codex 的服务端工具发起的调用，在 2026 年 11 月 1 日（北京时间）按次计费开始前对 DeepSeek API 用户免费。两个端点均有每账户 5 QPS 的限制。

## 适配的工具链

DeepSeek 表示 1017 针对自家的 Agent 框架 DeepSeek Harness（建议升级到 v0.2.1-rc.1 或更高版本）、腾讯 CodeBuddy 与 WorkBuddy 做了调优；模型通过带自反馈的强化学习训练，以支持从头到尾完整构建项目（从游戏到 3D 建模）。同期发布的配套技术论文题为《DeepSeek-V4.1-Flash: Pushing the Limits of KV Cache Compression》，聚焦 KV 缓存压缩。
