2026 年 11 月 16 日，阿里巴巴发布 Qwen4-Max。这是 Qwen 家族的新旗舰模型，也是 Qwen4 系列的首个完整模型。阿里巴巴称其为迄今为止 Qwen 家族中最强的模型，定位为面向工作、创作与研究场景的通用模型。

<!-- more -->

## 架构与能力

Qwen4-Max 采用 MoE 架构，总参数为 2.4 万亿，每次推理激活约 710 亿参数。模型支持文本、图像与视频输入，具备原生视觉能力，上下文窗口为 100 万 token。

阿里巴巴表示，Qwen4-Max 在编码、Agent 任务与视觉推理等主流基准上取得领先排名，在真实世界编码排行榜 Code Arena 上排名第 6，优于 Anthropic 的 Claude Fable 5.1、Moonshot 的 Kimi K3.1 Pro 与 Muse Wonder Full。

## 成本

在阿里巴巴的自有基准 Work360 上，Qwen4-Max 在覆盖 721 个专业领域的行业任务中整体优于上一代 Qwen3.8-Max，在高强度推理模式下 token 用量减少 35%，平均单任务成本降低约 60%。

QwenCloud 的按量付费 API 定价为：输入每百万 token 1.50 美元，输出每百万 token 4.50 美元，隐式缓存输入每百万 token 0.075 美元。与 Qwen3.8-Max 的 2.00 美元输入、6.00 美元输出相比，输入与输出价格均下降 25%，缓存输入价格下降 70%。

## 发布节奏与接入方式

Qwen4-Max 的发布分两步进行。11 月 11 日，阿里巴巴先在 Token Plan 订阅中开启预览版 qwen4-max-preview；11 月 16 日，正式版以模型 ID `qwen4-max` 上线 QwenCloud 按量付费 API。预览版将于 11 月 25 日退役。

开发者可通过 QwenCloud API、Token Plan 与 OpenRouter 接入 Qwen4-Max。API 支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 与阿里巴巴自有的 DashScope 协议。模型已在北京、新加坡、法兰克福、弗吉尼亚、东京与香港等区域上线。

## 开源与安全

Qwen4-Max 为闭源权重模型，用户无法自行下载与定制。阿里巴巴表示，Qwen4 系列中较小的模型后续将以开源权重形式发布。

阿里巴巴同时表示，在 Qwen4-Max 的训练中对网络安全相关训练数据采取了更为审慎的筛选方式。
