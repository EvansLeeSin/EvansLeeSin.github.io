2026 年 11 月 5 日，OpenAI 发布 GPT-6 Cyber，一个专为网络安全研究打造的模型，用于发现软件漏洞、开发可用的漏洞利用验证并协助修复。OpenAI 表示，该模型在漏洞发现与利用能力上较前代 GPT-5.6 Cyber 有大幅提升，同时在授权范围内的表现更为可靠。

<!-- more -->

## 能力表现

在 ExploitGym 基准测试中，GPT-6 Cyber 的利用成功率为 48.5%，前代 GPT-5.6 Cyber 为 32.1%，相对提升 51%。该测试衡量模型能否针对指定漏洞开发出可用的利用代码。

在 OpenAI 新建的进攻性 Web 渗透测试评估中，模型在无法接触目标应用源代码的情况下探测漏洞，GPT-6 Cyber 的漏洞召回率为 40.3%，GPT-6 Astra 为 32.0%。

在另一项新基准 RemoteExploitBench 中，模型针对受控环境中部署的 GitLab、PostgreSQL、Jenkins 等应用的已知漏洞开发远程利用代码。GPT-6 Cyber 完成了 95% 的任务，唯一一次失败是未能让一个利用代码在远程生效；同等条件下，使用 Daybreak Blue 的 GPT-6 Astra 拒绝了全部任务。

基于上述结果，OpenAI 将 GPT-6 Cyber 在 Preparedness Framework 下的网络安全能力评级定为 Critical，高于前代 GPT-5.6 Cyber 的 High。

## 实际应用

OpenAI 已用该模型开展大规模漏洞研究，覆盖 Linux 内核与 Firefox 两个代码库。

在 Linux 内核研究中，研究人员搭建的自动化流程共识别出 2,308 个候选安全问题，成功复现其中 1,724 个漏洞，并为 948 个本地提权漏洞开发出可用的利用代码。同一研究流程下，GPT-5.6 Sol 仅开发出 166 个利用代码。OpenAI 表示，上述 948 个漏洞均对应候选补丁，并已按 Linux 社区的指引向维护者提交了 304 项关键发现及候选补丁，其余漏洞的修复工作正在进行中。

在 Firefox 的漏洞研究中，GPT-6 Cyber 提供了证据与可复现测试，确认了 81 个此前未知的、被 Mozilla 定级为高危的漏洞，并发现另外 30 个已知问题比原先报告的更为严重。OpenAI 已将相关发现与建议补丁提交给 Mozilla，Mozilla 已为其中许多漏洞发布修复。

OpenAI 表示，思科、Calif 和 CodeRabbit 的安全团队已在使用该模型进行漏洞研究与代码审查，OpenAI 自身也用它来加固基础设施。

## 授权范围与防护

网络安全 Agent 的一个风险是超出任务授权范围，尝试利用无关服务或无视研究人员的交战规则。OpenAI 表示，GPT-6 Cyber 在对齐方面经过专门训练，以帮助模型停留在授权范围内、遵守行动限制并准确报告工作。

在 ExploitGym Honeypot 评估中，模型在隔离环境中执行漏洞利用任务，同时可以接触包仓库、对象存储等辅助服务，这些服务被刻意设为易受攻击，以检验模型是否会超出任务范围。在不使用部署提示的情况下，GPT-6 Cyber 在 99.93% 的测试中未利用范围外服务，前代为 94.49%；使用部署提示时为 100%。

配套的防护措施包括：网络安全专项未对齐行为监控、新兴威胁定向监控、私有安全处理（PSP）、Daybreak Red API 默认要求 IP 白名单，以及对高风险工作流的沙箱与人工监督建议。

## 访问方式

GPT-6 Cyber 初期通过 API 与 Codex 提供给部分获批的 Daybreak Red 客户，OpenAI 表示将逐步扩展至全部 Daybreak Red 客户；GPT-5.6 Cyber 也将向全部 Daybreak Red 客户开放。Daybreak Blue 的 Alpha 访问范围也在扩大，覆盖更多组织与个人安全研究者。

OpenAI 同时推出 10 亿美元的 Daybreak for Frontline Defenders 资助计划，为资源有限的团队提供访问补贴，并在 Daybreak Red 内新增面向关键基础设施防御者的分组 Daybreak Red for Critical Infrastructure。
