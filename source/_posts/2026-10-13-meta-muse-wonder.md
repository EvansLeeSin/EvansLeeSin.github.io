2026 年 10 月 12 日，Meta 发布 Muse Wonder 与 Muse Wonder Full 两款模型。Meta 称，这是其迄今能力最强的模型，定位为前沿级（frontier）模型，面向个人与专业场景的 Agent 任务。该系列由 Meta Superintelligence Labs 团队打造。

<!-- more -->

## 发布与获取

Muse Wonder 现已通过 Meta Model API 与 Muse Code 提供访问。Meta 表示，该模型后续还将进入 Muse 应用，付费订阅用户优先获得，具体日期未公布。

Muse Wonder Full 定位更高的一款，暂不通过 API 按量付费提供，仅面向 Muse Code 的付费订阅用户：Power 档每月 50 美元，Maximum 档每月 200 美元。Meta 未宣布两款模型的开放权重或开源许可。

## 定价

Meta 公布的 Muse Wonder API 价格为：输入每百万 token 4 美元，输出每百万 token 20 美元；缓存输入每百万 token 0.20 美元；网页搜索每 1000 次查询收费 2.50 美元；长上下文不额外收费。上下文窗口为 100 万 token，支持文本、图像、视频、音频等多模态输入。

## 性能与功能

在 Artificial Analysis 的 Intelligence Index 上，Muse Wonder Full 得 56 分，Muse Wonder 得 52 分，略低于 Claude Opus 5.5 的 58 分。Meta 表示，在部分任务上 Wonder 表现超过 Claude Fable 与 GPT-6 Astra。另据报道，Muse Wonder Full 在 DeepSWE 1.1 上得分 79.0，在 Terminal-Bench 4.0 上的成功率从 33% 提升至 57%。

Meta 重点介绍的两个能力是"Active Memory"与"Active Focus"：前者让模型跨会话保留关键信息，后者面向多步骤任务，旨在让 Agent 在跨应用导航中保持任务聚焦、尝试不同方案。

## 安全

据其模型卡披露，若不加缓解措施，不能完全排除 Muse Wonder Full 在化学与生物高风险领域达到其高风险阈值的可能；经过安全后训练与系统级分类器后，残余风险被评为中等或更低。Meta 表示将发布更完整的安全报告，未给出时间。

## 背景

此次发布距离 Meta Superintelligence Labs 启动约一年多，是该公司在 AI 订阅收入方向上的又一步。发布当日 Meta 股价上涨超过 4%。
