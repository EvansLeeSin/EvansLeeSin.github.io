2026 年 11 月 17 日，微软在旧金山举行的 Ignite 2026 大会上发布了七款 MAI 模型，覆盖编程、网络安全、图像生成、实时语音与转录等场景。微软 AI 表示，这批模型以性价比为卖点，面向需要全天候运行 AI Agent 的企业客户。

<!-- more -->

## 编程模型

MAI Code 2 面向多步骤任务、复杂重构与 Agent 驱动开发等高要求编程工作。微软表示，在 DeepSWE 1.1、Terminal Bench 2.1、SWE-Atlas 与 FrontierCode v1.1 四项基准的平均分上，MAI Code 2 达到 OpenAI GPT-6.1 Sol 编程性能的 98%，价格约为其 40%；与 Anthropic Claude Opus 5.5 相比，达到其 96% 的性能，价格约为其 5%。微软同时表示，两款编程模型目前未针对基础科学研究与长周期 Agent 工作等更难的问题做专门调优。

MAI Code 2 Flash 面向高频日常编程任务，包括代码解释、针对性修改、常规修复与快速迭代。微软表示，该模型达到 GPT-6 Luna 的性能水平，价格约为其 65%；达到 Haiku 5.5 的性能水平，价格约为其 20%。

两款编程模型均已接入 GitHub Copilot。MAI Code 2 Flash 同时通过微软 Foundry 提供有限访问预览。上述价格对比按发布期的促销价格计算，微软未公布两款模型的标准定价。

## 网络安全模型

MAI Cyber 2 Flash 面向网络安全场景，覆盖代码漏洞发现、验证与修复。微软表示，在 CyberGymE2E 基准上，该模型的质量与 GPT-6 Astra 相当，单任务成本不到其 2%。微软称，该模型面向持续安全监控与生产系统中的漏洞修复，将首先提供给微软安全产品用户；从 12 月中旬起，符合条件的客户在代号 MDASH 的产品中将切换到该模型。

## 图像、语音与转录

MAI Image 2.7 与 MAI Image 2.7 Flash 面向图像编辑与生成。微软表示，MAI Image 2.7 在 Artificial Analysis 的图像编辑榜单上排名第一，优于 GPT Image 2.6 Sunburst（max），价格约为其五分之一。两款模型已在微软 Foundry 开放公开预览。

MAI Realtime 1 面向实时语音对话场景。MAI Transcribe 2 则作为 Dragon Copilot Transcribe 的底层模型，面向医疗转录场景。

## 路由与授权

Microsoft Decision 1.1 是一型路由模型，根据任务将请求分配给规模不同的模型，现已正式可用。

微软同时推出 MAI Licensed Weights 授权方式，客户可在自有数据上定制前沿 MAI 模型，并在自己的 Azure 环境中运行，访问权限由客户自行控制。

## 背景

微软 AI 首席执行官 Mustafa Suleyman 在 Ignite 主题演讲中介绍了这批模型。微软表示，七款模型均已在其第二代 Maia 200 数据中心加速器上投入生产运行，该加速器每瓦 token 产出比上一代高 1.7 倍。

此次发布延续了微软 AI 部门今年的自研模型路线。微软今年 6 月在 Build 2026 大会上发布了首批 MAI 模型，包括 MAI-Thinking-1、MAI-Code-1-Flash、MAI-Image-2.5、MAI-Transcribe-1.5 与 MAI-Voice-2。
