2026 年 10 月 21 日，OpenAI 宣布与 Google Cloud 达成合作，将其前沿模型与 Codex 智能体工作流引入 Google Cloud 的模型目录 Model Garden。Google Cloud 同日发布了同名公告，双方称此次合作面向企业级客户。

<!-- more -->

## 上线模型

Google Cloud 的公告列出了首批三款模型，目前正以私有预览的形式向部分企业客户开放，后续还会有更多模型加入：

- **GPT-6 Astra**：OpenAI 的旗舰模型，面向代码、计算机操作、专业任务和科研等高强度工作。
- **GPT-6.1 Sol**：以更低的成本提供接近 Astra 的智能水平，面向智能体编程、计算机操作和专业办公场景。
- **GPT-6 Luna**：快速、低成本的模型，面向日常高并发任务。

## 购买方式与时间

OpenAI 模型将通过 Google Cloud Marketplace 购买，使用记录统一汇总到一张 Google Cloud 账单，可抵扣客户已有的云消费承诺额度，并计入 Google Cloud 的 Flexible Savings Plans。

时间方面：OpenAI 在公告中称正式版计划"在未来几周内"上线，有需求的客户现在可以通过双方网站上的意向表单申请访问。

## Codex 与工具集成

除模型本身外，Codex 智能体工作流也是此次合作的一部分。Google Cloud 表示，客户可以将本地的 Codex 命令行工具和 Codex 桌面应用连接到其平台进行推理。OpenAI 则在公告中提到，其模型还将进入 Google 的 Antigravity 编码工具和 Gemini Agent。

面向受监管行业的客户，可以使用 Google Cloud 的访问控制、数据治理工具和基础设施来构建智能体工作流。

## 背景

据 Reuters 报道，OpenAI 与微软的独家分发安排已于今年 4 月到期，此后 OpenAI 将分发渠道先后拓展到 AWS 和如今的 Google Cloud，使其模型集齐美国三大云厂商。去年 Google Cloud 曾与 OpenAI 达成云协议，为其提供更多算力。

OpenAI 总裁 Greg Brockman 在公告中表示："此次合作是让我们的顶级模型和 Codex 在客户已构建的环境中触手可及的重要一步。"Google Cloud 首席执行官 Thomas Kurian 则表示，公司专注于为客户提供广泛的模型选择，包括 OpenAI 的模型。OpenAI 同时强调，微软仍是其首要云合作伙伴。
